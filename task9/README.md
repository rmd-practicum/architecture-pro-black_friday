# orders

|Операция чтения|Primary / Secondary|Допустимая задержка|Обоснование|
|---|---|---|---|
|Поиск истории заказов конкретного пользователя|Primary|0|Пользователь должен видеть все заказы, в т.ч. только что размещенные|
|Отображение статуса заказа|Secondary|минуты|Задержка обновления статуса (например, "новый" -> "собирается") не введет пользователя в заблуждение|

# products

|Операция чтения|Primary / Secondary|Допустимая задержка|Обоснование|
|---|---|---|---|
|Поиск товаров по категориям и фильтрация по диапазону цен|Secondary|минуты|Товары добавляются и меняются относительно редко|
|Описание товара на странице продукта|Secondary|минуты|Информация о товаре обновляется относительно редко, задержка отображения допустима|
|Получение остатков|Primary|0|Устаревшие данные могут привести к размещению заказа на распроданный товар|

# carts

|Операция чтения|Primary / Secondary|Допустимая задержка|Обоснование|
|---|---|---|---|
|Получение текущей корзины|Primary|0|Устаревшие данные в корзине введут пользователя в заблуждение и могут привести в т.ч. к повторному добавлению товара в корзину|
