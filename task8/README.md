## Метрики для отслеживания горячих шардов

- `db.aggregate([{ $shardedDataDistribution: { } }])`: обзор распределения данных по шардам по всем коллекциям
- `db.products.getShardDistribution()`: распределение данных коллекции товаров по шардам
- `db.adminCommand({ serverStatus: 1 }).opcounters`: текущая нагрузка на шарде

## Механизм автоматического перераспределения данных

Изменить ключ шардирования: например, использовать идентификатор товара. Это приведет к равномерному распределению данных по шардам, однако пострадает производительность чтения товаров по категориям:

```
db.adminCommand({ reshardCollection: "somedb.products", key: { _id: "hashed" } })
```
